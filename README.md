Northstar Online Retail — Sales Data Cleaning & Analysis

### Project Overview

This project analyzes Northstar Online Retail sales data to identify data-quality issues, clean and prepare the dataset, perform SQL-based analysis, and create an interactive Tableau dashboard.

The project demonstrates an end-to-end data analytics workflow from raw data to business recommendations.

### Tools Used

- Microsoft Excel
- SQL
- Google BigQuery
- Tableau Public
- GitHub

Data Quality Work

### The raw dataset contained issues including:

- Duplicate records
- Missing values
- Date issues
- Inconsistent text values
- Extra spaces
- Invalid numerical values

The data was cleaned while preserving questionable records for investigation rather than making unsupported assumptions.

### Key Results

- Total Revenue: $272,378
- Total Orders: 250
- Average Revenue per Order: $1,098.30
- Top Product: Laptop
- Top City: Seattle
- Top Category: Electronics

### Business Insights

### Product Performance

Laptop generated the highest revenue at $95,823, followed by Phone at $65,596 and Tablet at $49,020.

### Category Performance

Electronics generated $265,222.50 in revenue compared with $7,155.50 from Accessories.

### Geographic Performance

Seattle was the highest-revenue city with $47,462.50 in sales.

### Payment Status

191 orders were paid, 58 were pending, and 1 order had a missing payment status.

## Dashboard

The Tableau dashboard provides:

- Total Revenue KPI
- Total Orders KPI
- Average Revenue per Order KPI
- Top Product KPI
- Monthly Revenue Trend
- Revenue by Product
- Revenue by City
- Revenue by Category
- Orders by Payment Status
- Interactive Date, City, and Product filters

## Business Recommendations

1. Continue monitoring Laptop, Phone, and Tablet performance because these products generate the majority of revenue.
2. Investigate opportunities to increase sales in lower-performing categories.
3. Review pending payments to identify potential cash-flow opportunities.
4. Investigate missing and invalid source-data values to improve future reporting accuracy.

## Project Outcome

This project demonstrates the ability to transform raw and imperfect sales data into a cleaned analytical dataset, generate business insights using SQL, and communicate findings through an interactive Tableau dashboard.
